CAISSEKOM SMARTPRICE v1.7 — CATALOGUE INTELLIGENT

Nouveautés :
- marque, catégorie, référence fabricant, description et caractéristiques ;
- jusqu'à 5 photos compressées par produit ;
- prix promotionnel avec dates ;
- badges Nouveau et Vedette ;
- produits associés ;
- recherche par code, désignation, marque, catégorie et référence ;
- fiche client enrichie et galerie photos ;
- indicateurs promotions, vedettes, catégories et marques.

Mise à jour Supabase :
1. Ouvrir Supabase > SQL Editor > New query.
2. Copier smartprice-v1.7-migration.sql.
3. Cliquer Run.
4. Publier tous les fichiers sur GitHub/Vercel.
5. Dans Administration > Base centrale, cliquer une fois sur Vider le cache application.

Compatibilité :
La v1.7 conserve le scanner, l'import Excel, Supabase, le multi-magasins,
les comptes utilisateurs, les promotions v1.6 et le connecteur Caissekom reporté.
