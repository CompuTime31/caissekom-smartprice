CAISSEKOM SMARTPRICE v1.0-alpha3

Nouveautés :
- Base centrale Supabase optionnelle
- Synchronisation manuelle articles + paramètres
- Cache local de secours
- Mode client cloud-first
- Fichier SQL de préparation inclus

Installation : copiez tous les fichiers dans le dépôt GitHub puis Commit et Push.
Configuration cloud : exécutez supabase-setup.sql dans Supabase, puis ouvrez Administration > Base centrale.
Attention : les politiques d'accès sont ouvertes pour cette phase alpha et seront sécurisées dans alpha4.
