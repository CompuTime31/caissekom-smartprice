# Installation

## Prérequis
- Node.js 20 ou plus récent
- npm
- Un projet Supabase pour la connexion serveur

## Commandes
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

Pour Vercel, importer le dépôt puis ajouter les variables `VITE_SUPABASE_URL` et `VITE_SUPABASE_ANON_KEY`.


### Build 007 — Installation locale Windows

Lancer `INSTALLER-SMARTPRICE.bat` en tant qu’administrateur, puis suivre l’assistant `/setup`.
